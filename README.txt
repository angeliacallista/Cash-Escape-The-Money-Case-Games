CASG ESCAPE GAMES
=================

CARA BERMAIN OFFLINE (SOLO / INDIVIDU)
1. Ekstrak file ZIP ini ke folder di komputer atau HP.
2. Buka folder Casg EScape games.
3. Buka index.html dengan browser yang tersedia (Chrome, Edge, Firefox, Safari, atau browser modern lain).
4. Pilih MAIN SOLO. Game solo dan seluruh soal dapat dimainkan tanpa paket data/internet setelah file diekstrak.
5. Setiap soal sekarang menampilkan PETUNJUK/DATA. Tekan tombol “Tampilkan petunjuk” untuk mendapat arahan tambahan tanpa menampilkan jawaban benar.

KONTROL
- PC: WASD atau tombol panah untuk bergerak; E untuk memeriksa bukti; Space/J untuk lompat jika tersedia pada versi ini.
- HP: gunakan tombol kontrol di layar; miringkan ke landscape jika diminta.

MULTIPLAYER
- Buat Room/Gabung Room membutuhkan koneksi internet karena menggunakan layanan PeerJS publik.
- Mode solo tidak memerlukan koneksi internet.

KOMPATIBILITAS
- Game berbentuk HTML/CSS/JavaScript standar, bukan aplikasi khusus Chrome. Bisa dibuka di browser modern yang mendukung Canvas.
- Pada sebagian browser HP, membuka file HTML lokal bisa dibatasi oleh pengaturan perangkat. Jika begitu, coba browser lain atau pindahkan folder hasil ekstrak ke penyimpanan lokal perangkat.
- Untuk membagikan game melalui tautan web yang bisa dibuka siapa saja, game harus diunggah ke hosting; hosting tersebut memerlukan internet saat diakses. ZIP ini sendiri dapat dimainkan secara lokal tanpa paket data untuk mode solo.

CATATAN
- Kunci jawaban tidak ditampilkan pada panel soal; seperti game HTML biasa, logika jawaban tetap dapat diperiksa melalui source code.
